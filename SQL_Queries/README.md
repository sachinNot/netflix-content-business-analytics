# SQL Queries

This folder contains SQL scripts used for Netflix Content & Business Analytics.

## Database
- Database: MySQL
- Database Name: netflix_analytics
- Table: netflix_titles

## Analysis Covered
1. Total Movies and TV Shows
2. Year-wise Content Analysis
3. Top 10 Content-Producing Countries
4. Ratings Distribution
5. Genre Analysis
6. Movie Duration Analysis
7. CTE and Subqueries
8. RANK and DENSE_RANK
9. LAG and LEAD
10. Running Total
11. Year-over-Year Growth

- Netflix_Advanced_SQL_Analysis.sql
