# Excel Data Cleaning & Preparation

This folder contains the cleaned Netflix dataset prepared for data analysis.

## Files Included

| File Name | Description |
|---|---|
| Netflix_Cleaned.csv | Cleaned dataset after removing inconsistencies |
| Netflix_Final.csv | Final dataset used for analysis |

## Dataset Information

- Total Records: 8,807
- Total Columns: 12
- Movies: 6,131
- TV Shows: 2,676

## Data Preparation

- Checked missing values.
- Removed duplicate records.
- Standardized column formats.
- Prepared data for MySQL and Power BI.
- Validated unique show IDs.

## Tools Used

- Microsoft Excel
- Python (Pandas)

## Project Outcome

The cleaned dataset was used for SQL analysis, Python EDA, and Power BI dashboard development.
