# Python EDA – Netflix Data Analysis

This folder contains Python scripts and visualizations created for Exploratory Data Analysis (EDA) of the Netflix Titles dataset.

## Objectives

- Explore Netflix Movies and TV Shows.
- Analyze content distribution.
- Identify popular genres.
- Analyze movie duration.
- Explore ratings distribution.
- Analyze TV Show seasons.
- Generate visual insights from the dataset.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Python Analysis Files

| File Name | Description |
|---|---|
| netflix_eda.py | Overall Netflix dataset analysis |
| genre_analysis.py | Genre-wise content analysis |
| movie_duration.py | Movie duration analysis |
| rating_analysis.py | Content ratings analysis |
| tv_show_analysis.py | TV Show analysis |

## Visualizations

The folder includes visualizations such as:

- Content Type Analysis
- Genre Analysis
- Movie Duration Analysis
- Top 10 Countries
- Top 10 Genres
- Top 10 Ratings
- TV Show Seasons
- Yearly Content Trends

## Dataset Information

- Dataset: Netflix Titles
- Total Records: 8,807
- Total Columns: 12
- Movies: 6,131
- TV Shows: 2,676

## Project Outcome

Python EDA helped identify patterns and trends in Netflix content and supported the development of the Power BI dashboards.
